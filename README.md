# MiChat — установщики клиента

Здесь лежат только собранные установщики MiChat: внутреннего чата для локальной
сети предприятия. Исходный код в этот репозиторий не выкладывается.

Репозиторий существует ради одного — чтобы установщик можно было скачать по
обычной ссылке, без учётной записи на файловом сервере.

## Скачать

Все выпуски — на вкладке [Releases](../../releases). Берите файл
`michat-client-<версия>.exe` из самого свежего.

Описание у каждого выпуска одно и то же: это короткая справка о программе — что
она умеет, как найти сотрудника, чем группы различаются, как передать файл или
картинку. Списка изменений там нет намеренно: сюда приходят те, кто ставит MiChat
впервые, и им нужно знать, что это за программа, а не что поменялось за неделю.
Та же справка есть в самой программе: ☰ → «О приложении».

## Как это ставится

Порядок установки сервера и рабочих станций, вход в админ-панель и внесение
сотрудников списком — в [INSTALL.md](INSTALL.md).

## Проверить, что скачалось то самое

У каждого выпуска рядом с установщиком лежит `SHA256SUMS`. Сверьте:

```powershell
Get-FileHash michat-client-1.4.31.exe -Algorithm SHA256
```

Полученная строка должна совпасть со строкой из `SHA256SUMS`.

**Приложение делает эту проверку само и не полагается на вашу.** Контрольную
сумму клиент получает не отсюда, а от своего сервера по защищённому каналу с
закреплённым отпечатком сертификата, и сверяет с ней скачанный файл. Не сойдётся
— установщик будет удалён, не запустившись. Поэтому подменить пакет здесь нельзя
так, чтобы подменённое установилось: этот репозиторий — место хранения байтов, а
не источник правды о том, какие байты правильные.

## Обновляться вручную обычно не нужно

Установленный клиент сам покажет полосу «Доступна версия …» в верхней части окна,
когда сервер предложит новую. Нажатие на «Обновить» скачивает пакет, проверяет
его и ставит. Скачивать что-либо отсюда руками нужно только в двух случаях:

- ставите MiChat на новую машину впервые;
- обновление не проходит, и в отделе АСУ попросили поставить пакет вручную.

## Что нужно для установки

Windows 10 или 11, 64 бита. Ничего доустанавливать не требуется: среда .NET
входит в установщик. Установка запрашивает права администратора.

Адрес сервера и отпечаток его сертификата уже вкомпилированы в установщик —
после установки приложение подключается само, вводить ничего не нужно.

## Куда писать, если не работает

В отдел АСУ. Приложите журнал: в MiChat откройте **Настройки → Журнал работы →
«Собрать журнал»**. Кнопка складывает записи в один архив на рабочем столе и
показывает его в проводнике — этот файл и приложите к письму.

Если MiChat не запускается вовсе, журнал лежит здесь:

```
%LocalAppData%\MiChat\logs\michat-client-*.log
```

В журнал не попадают тексты сообщений, телефоны и имена файлов — его можно
пересылать, не просматривая.
